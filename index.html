What the application does

A thoughtful workflow.

Current features and the next steps, clearly separated.

01 /
Implemented

Connect the right channel

Official Google OAuth verifies the Rhen channel and renews authorized access. Credentials stay in the operator’s dedicated Windows Credential Manager entries.

02 /
Implemented · local only

Prepare, then review

Local checks prepare approved video files, titles, descriptions, tags, audience decisions, and thumbnail assets. File fingerprints and a job journal help prevent duplicate submissions.

03 /
Planned · disabled

Upload with permission

Private uploads, processing verification, eligible thumbnail updates, and approved scheduling are planned. They are not currently active. Scheduling and public release require separate authorization.

Personal use. Clear boundaries.

This is an owner-operated desktop tool, not a public sign-up service. It is configured for one Rhen channel. This website cannot sign in to Google or upload videos.

Your account data stays purposeful.

Google access is used for the disclosed channel-management workflow. The website has no analytics, advertising, embedded players, or account-data collection forms.
